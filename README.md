# AI Agents Collection

A collection of production-ready AI agent workflows and multi-agent systems for automating complex tasks.

## Projects

### 🎨 Instagram Content Generator
**Path:** `/instagram-content-generator`

An intelligent multi-agent system that automates the entire Instagram content creation process. This workflow uses 5 specialized AI agents working in two crews to generate complete Instagram posts including ad copy and visual descriptions.

**Features:**
- Automated market and competitor analysis
- Strategic campaign development
- Creative copywriting with multiple variations
- Professional photograph conceptualization
- Quality review and approval workflow

**Tech Stack:** Python, LangChain, OpenAI/Ollama, Web Scraping Tools

[View Project →](./instagram-content-generator)
